## Таксоны
Для классификации используют **систематические категории (таксоны)** — группы организмов, объединённых по общим признакам.

- **Вид** — элементарная единица систематики.
    
- **Бинарная номенклатура**: Научное название вида состоит из двух слов первое — Род, второе — Вид. Например, Волчеягодник обыкновенный, Пырей ползучий

##  Таксономическая иерархия: Растения и Животные

Важно помнить, что названия некоторых таксонов для растений и животных различаются.

- **Царство**: `Растения` / `Животные`
    
- **Отдел / Тип**: `Цветковые` / `Хордовые`
    
- **Класс**: `Однодольные` / `Млекопитающие`
    
- **Порядок / Отряд**: `Злакоцветные` / `Хищные`
    
- **Семейство**: `Злаковые` / `Псовые`
    
- **Род**: `Пшеница` / `Волк`
    
- **Вид**: `Пшеница твёрдая` / `Волк обыкновенный`
